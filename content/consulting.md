## 잘 맞는 요청

- “우리 팀에서 AI 코딩 에이전트를 써도 되는지” 판단하고 싶은 경우
- 자동화는 있는데 실패했을 때 추적·롤백·감사가 약한 경우
- PostgreSQL/Kubernetes/CI 병목을 빠르게 구조적으로 보고 싶은 경우
- 보안팀/플랫폼팀/개발팀 사이 의사결정 문서가 필요한 경우

## 산출물 예시

| 형태 | 결과물 |
|---|---|
| 1회 진단 | 리스크/우선순위 표, 즉시 고칠 항목, 보류할 항목 |
| 설계 리뷰 | 아키텍처 결정 기록(ADR), 권한·데이터 흐름, 실패 모드 |
| 자동화 점검 | CI/agent 실행 권한, secret 노출면, 로그/감사 추적 체크리스트 |
| 글쓰기/리서치 | 출처 기반 기술 브리핑, 블로그 초안, 내부 공유용 요약 |
